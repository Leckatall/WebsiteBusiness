# Academy

A full-stack educational web application built in PHP, inspired by platforms like Moodle. Designed to connect tutors and students through a structured course and lesson system.

## Features
- Role-based access control (Student, Tutor, Admin)
- Course creation, enrolment, and approval workflow
- Lesson management with due dates and student scoring
- File upload system with per-lesson file attachment
- Custom MVC framework (Router, Controllers, Models, Middleware, Views)
- Database migration runner
- RESTful routing

## Tech Stack
- **Backend:** PHP (custom MVC framework)
- **Database:** MySQL via PDO
- **Frontend:** HTML, CSS, Bootstrap 5, JavaScript (Fetch API)

## Setup
```bash
php setup.php
```
